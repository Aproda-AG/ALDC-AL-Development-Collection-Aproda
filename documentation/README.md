# documentation/

Project-specific technical documentation for this AL extension.

Each module or feature gets its own subfolder (e.g. `AuditTrail/`).
Files here are written and maintained by the project team — not generated by the ALDC framework.

> **Aproda layer note**: `README.md` (this file) is synced as part of the Aproda ALDC layer
> (see `tools/aproda-sync/aproda-sync.json`). All other files under `documentation/` are
> project-owned and are never touched by the syncer.
