## 2. Synthetic — library (`BcDataAccess.ps1`)

### Guard and clean-up

| ID | Case | Expected |
|---|---|---|
| S-12.1 | Guard: package matches id, displayName, publisher, `" PTE"` (leading space) | returns the package |
| S-12.2 | Guard: each attribute wrong in turn — id; displayName (also case only); publisher; `publishedAs = Dev`/`Global` | throws `BCDA: GUARD …`, names the attribute; **no** POST issued |
| S-12.3 | Guard: the *Data Administration* case — publisher `Aproda AG`, `PTE`, other id and name | throws; no POST |
| S-12.4 | Guard: non-GUID package id; lookup 404 | throws before any HTTP call / after the lookup; no POST |
| S-12.5 | Clean-up: one installed + two published-only packages | order: guard → `uninstallAndDeleteExtensionData` (installed) → wait → guard → `unpublish` ×3; ends `BCDA: CLEAN` |
| S-12.6 | Clean-up: uninstall/unpublish return 404 | tolerated; result clean |
| S-12.7 | Clean-up: a second package under the app id fails the guard (e.g. `publishedAs = Dev`) | the guarded listing stops **before any action** — no POST at all |
| S-12.8 | Clean-up never calls `Microsoft.NAV.uninstall` without data deletion, nor any action on a package id that was not returned by the guarded list in the same run | asserted on the mock call log |
